# P1 初始分配与受控试评

日期：2026-11-05。

A3 对超过 500 个任务的初始化已取消基于 C 解码结果的跨星试探。所有规模均先确定任务归属，再由 B/C 进行单星搜索。501 个存在观测冲突的任务构成的同一夹具中，A3 初始分配调用 C 的次数从 503 降为 0。

B 在初始化和局部阶段均可经运行时多次试评 C，比较后选择本次已校验候选。重分配整星重建通过 C 的 `rebuild` 接口，试评不会直接提交时间轴。运行时检查候选、截止时间和会话身份；非法输出不能靠 B 捕获异常变成有效结果。该能力已接入手工运行时和来源协调器的手工 B 适配层。

验证结果：

- Maven 全部 68 项测试通过。三个手工实例、8 个组合的 24 行结果与改前逐字段一致，并通过独立 oracle。
- 300 任务、种子 42 的来源组件组合完整运行轨迹与改前 72 行一致；初始收益 1603，最终收益 1618。此对照未触及超过 500 任务分支。
- 1000 任务真实场景在搜索截止时返回 285 条观测、收益 1972，经独立验证可行。这是一个截止检查点，不能据此比较改动前后的算法性能。

来源原生 A/B/C 仍通过来源协调器和专用接口运行，尚未直接统一到 `SolverContracts.A/B/C`；小实例自动种群下限差异也待核实。P1 仍在进行中。
