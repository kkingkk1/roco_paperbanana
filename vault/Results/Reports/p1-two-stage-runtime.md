# P1两阶段运行时验收

日期：2026-11-04。

本报告记录原P1任务2手工运行时的验收。程序提供A/B/C各两种两阶段手工策略，形成8个组合；跨星移动只在受影响卫星副本上编辑，并在完整调度可行且收益严格提高时接受。任务2后来按用户要求扩展为完整RKHMA拆分与重组，当前状态见[P1计划](../../Plan/mechanisms/P1-可运行求解器起点.md)。

策略借鉴RKHMA的机会数量、负载、重插、交换和可行插入思路，没有复现完整RKHMA，也没有引入额外收益奖励。
46项测试通过，覆盖8组合两阶段调用、编辑权限、移动回滚、累计局部范围和软硬截止。
该次测试使用的4个额外任务上限已取消，此报告保留当时事实，不代表新接口验收。

一个500任务、5卫星真实场景的工程烟测输出389条可行观测，收益2381，端到端计时4673.905毫秒。
运行时实际核验单核、Normal优先级及2 GiB Windows Job总提交内存上限。结果只用于工程验收，不表示相对RKHMA的性能。

完整命令、输入与源码哈希、实际观测及失败修正见[证据包](../Evidence/p1-two-stage-runtime/evidence.md)。
本报告验收时P1任务3尚未完成；后续结果见[手工实例枚举报告](p1-small-enumeration.md)。
